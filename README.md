# 🤖 Groq + LangChain AI Assistant

An interactive Generative AI application built using **LangChain, Groq, and Streamlit**.

This project allows users to interact with an AI model through a simple web interface and also translate text into different languages.

---

## 🚀 Features

### 💬 Ask AI
- Ask questions directly to the AI model.
- Get intelligent responses using Groq's LLM.
- Simple and interactive Streamlit interface.

### 🌍 Text Translation
- Enter any text you want to translate.
- Select the target language.
- Generate the translated text using LangChain and Groq.

### ⚡ Fast AI Responses
- Uses Groq's high-speed inference.
- Powered by the `openai/gpt-oss-20b` model.
